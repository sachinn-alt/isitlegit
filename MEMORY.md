## 📌 Project Overview

**IsItLegit** is an open-source, client-first cybersecurity intelligence engine and Progressive Web App (PWA). It allows users to inspect suspicious links, SMS messages, WhatsApp forwards, email headers, and QR codes **without clicking or visiting them**.

Unlike standard threat blockers that only look for known malware, **IsItLegit** features an **Authentic Alert & Legitimacy Classifier**: it detects and validates genuine security notifications, bank 2FA OTP codes, and transactional alerts (e.g., Chase, HDFC, SBI, PayPal), explaining *why* an alert looks alarming vs. *why* it is authentic.

## 🏛️ Core Principles & Architecture

### 1. 100% Zero-Knowledge Client Privacy
- **No Remote Telemetry or Logging**: User queries, scanned URLs, and text messages are never logged on any remote server.
- **Local Web Crypto Vault**: Sensitive API keys and credentials entered by the user are encrypted on-device using **AES-GCM 256-bit** with PBKDF2 key derivation via the browser's native Web Crypto API (`src/utils/crypto.ts`).
- **Dexie IndexedDB**: Local scan history and bookmarked reports are stored securely in the browser's IndexedDB (`src/db/database.ts`).

### 2. Standalone Zero-Cost Intelligence (Offline-First)
- Runs complete offline heuristic analysis without needing external API keys or paid services:
  - **Homoglyph & Punycode Detection**: Identifies Cyrillic, Greek, or spoofed character substitutions (e.g., `раурal.com` vs `paypal.com`).
  - **Shannon Entropy Analysis**: Detects randomized/high-entropy subdomains and paths commonly generated by phishing kits.
  - **Subdomain Deception**: Catches patterns like `paypal.com.attacker-domain.xyz`.
  - **RDAP / WHOIS Heuristics**: Queries public ICANN/RDAP endpoints client-side to flag domains registered less than 30 days ago.
  - **Social Engineering Heuristics**: Analyzes artificial urgency, coercive threats, fake lottery claims, and suspicious payment requests.

### 3. Optional Multimodal Cloud AI
- Users can optionally supply their own API keys for enhanced deep analysis:
  - **Google Gemini 2.0 Flash** (`src/services/gemini.ts`): Multimodal visual inspection of screenshots and advanced contextual scam deconstruction.
  - **Amazon Bedrock Claude 3.5 Sonnet** (`src/services/bedrock.ts`): Enterprise threat reasoning and validation.
  - **VirusTotal & Google Safe Browsing** (`src/services/virustotal.ts`, `src/services/safe-browsing.ts`): Additional reputation feeds.

### 4. PWA with Web Share Target
- Fully installable on iOS, Android, macOS, and Windows.
- Registered **Web Share Target** (`manifest.webmanifest`) enables users to tap "Share" on any suspicious text or link inside WhatsApp, SMS, or Telegram and send it directly into IsItLegit for instant inspection.

### 5. Model Context Protocol (MCP) Server
- Located at `mcp/server.js`.
- Exposes threat intelligence over standard I/O (stdio) for AI assistants (Claude Desktop, Cursor, Antigravity):
  - `check_url`: Analyzes URLs for brand spoofing, lookalikes, entropy, and malicious TLDs.
  - `check_message`: Scans messages for urgency, fraud, and social engineering.
  - `verify_authenticity`: Confirms whether unexpected 2FA OTP codes or security alerts are genuine.

## ⚙️ Environment Variables (`.env.local`)

All external services are **optional**; the app operates completely offline without them:

- `VITE_GEMINI_API_KEY`: Google Gemini API key for multimodal screenshot and OCR reasoning.
- `VITE_VT_API_KEY`: VirusTotal API key for live malicious URL checks.
- `VITE_SB_API_KEY`: Google Safe Browsing Lookup API key.
- `VITE_AWS_ACCESS_KEY_ID`: AWS Access Key for Bedrock Claude 3.5 runtime.
- `VITE_AWS_SECRET_ACCESS_KEY`: AWS Secret Key for Bedrock.
- `VITE_AWS_REGION`: AWS Bedrock region (default: `us-east-1`).

## 🧪 Scoring Logic & Verdict Scale

The scoring engine (`src/engine/scoring.ts`) computes a weighted risk score from `0` to `100`:

| Score Range | Verdict | Color Code | Plain-English Meaning |
|---|---|---|---|
| **0 – 25** | `SAFE` | Emerald (`#10B981`) | Legitimate brand, valid domain age, genuine 2FA OTP, or clean heuristics. |
| **26 – 65** | `SUSPICIOUS` | Amber (`#F59E0B`) | Unverified domain age, moderate urgency language, unusual redirect, or unconfirmed sender. |
| **66 – 100** | `DANGEROUS` | Rose / Red (`#EF4444`) | Homoglyph impersonation, credential harvesting pattern, fake OTP interception, or known malicious feed match. |

## 🚀 Deployment & CI/CD Architecture

### 1. AWS Amplify Hosting
- **Build Spec**: Configured in [`amplify.yml`](amplify.yml) with automatic Node 20 runtime (`.nvmrc` + `nvm use 20`).
- **SPA Rewrites**: For React Router deep links to avoid 404 on refresh, configure in AWS Amplify Console (*App Settings* → *Rewrites and redirects*):
  - **Source**: `</^[^.]+$|\.(?!(css|gif|ico|jpg|js|png|txt|svg|woff|woff2|ttf|map|json|webp)$)([^.]+$)/>`
  - **Target**: `/index.html`
  - **Type**: `200 (Rewrite)`
- **Manual Zip Deploy**: Run `python scripts/package_deploy.py` to create a Unix-standard `isitlegit-deploy.zip` with forward slashes `/`.

### 2. GitHub Pages & CI
- **Automated Workflow**: [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) runs unit tests and deploys `dist/` to GitHub Pages.
- **Custom Domain Warning**: [`public/CNAME`](public/CNAME) specifies `isitlegit.app`. If deploying to GitHub Pages without DNS pointing to GitHub, this will trigger a domain check error. Ensure DNS A records point to GitHub's IPs (`185.199.108.153`, etc.) or delete `CNAME`.

### 3. Serverless Backend (AWS SAM)
- SAM template configured at [`template.yaml`](template.yaml) with `Metadata: BuildMethod: esbuild` targeting Node 20.
- Handler package defined in [`backend/lambda/package.json`](backend/lambda/package.json).

## 🤖 Guidelines for AI Agents & Pair Programmers

When working on this codebase:
1. **Preserve Privacy Invariants**: NEVER introduce code that transmits user input (URLs, text, email bodies) to external logging or analytics services. All core intelligence must remain functional in-browser.
2. **Offline-First Fallbacks**: Any feature utilizing Cloud AI (Gemini/Bedrock) must have a graceful offline heuristic fallback in `src/engine/`.
3. **Run Tests After Engine Edits**: Whenever altering `url-analyzer.ts`, `email-analyzer.ts`, `legitimacy-verifier.ts`, or `scoring.ts`, always run `npm test` to verify existing detection tests pass.
4. **Maintain Aesthetics**: The application uses a high-contrast cybernetic theme (dark backgrounds, neon accents, HUD reticles, smooth animations using Tailwind CSS v4 and Framer Motion). Keep visual components sleek, readable, and responsive.
5. **Keep MEMORY.md Updated**: When adding new engines, services, MCP tools, or altering core architecture, update this `MEMORY.md` file accordingly.
